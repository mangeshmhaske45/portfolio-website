# Mangesh Mhaske — AWS Cloud & DevOps Portfolio

A responsive static portfolio website built with HTML, CSS and JavaScript.

## Files

- `index.html` — portfolio content
- `style.css` — responsive dark DevOps theme
- `script.js` — mobile navigation and footer year
- `assets/` — place your resume, profile photo and favicon here

## Run locally

Open `index.html` in a browser.

## Deploy to GitHub Pages

1. Create a GitHub repository, for example `portfolio-website`.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Push to the `main` branch.
4. GitHub → Settings → Pages.
5. Under Build and deployment, choose `Deploy from a branch`.
6. Select `main` and `/root`, then Save.

## Before publishing

Update:
- LinkedIn URL in `index.html`
- GitHub URL in `index.html`
- Add `assets/resume.pdf`
- Optionally add `assets/profile.jpg`
- Review project descriptions so they exactly match your real project responsibilities.
